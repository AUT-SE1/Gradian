# بررسی نهایی T12 — گرادیان

تاریخ: 2026-10-20 — ورودی `Gradian(20261020-122909).zip`

بررسی مستقل T12 و تحویل مرحله‌ای انجام شد. پذیرش نهایی کامل **BLOCKED_DESIGN** است: انتهای فریم دانشجو مرجع کامل ندارد و T06 بسته نشده است. build یا smoke test شکست نخورده‌اند.

## تغییرات

- تست جدید `frontend/tests/t12-final.cjs` با ورودی واقعی برنامه و پاسخ‌های API کنترل‌شده مطابق قرارداد موجود؛ ۴۸ حالت و refresh در ۱۶ ترکیب.
- اصلاح race در تست T05: انتظار unavailable فقط در کارت صفحه مقصد؛ پیام موجود در سایدبار دیگر قبل از پایان مسیریابی تست را عبور نمی‌دهد.
- به‌روزرسانی دو سند ریشه، گزارش و شواهد جاری. کد اجرایی محصول، UI، API و dependencies تغییر نکردند؛ اشکال محصولی تأییدشده‌ای که نیازمند تغییر باشد یافت نشد.

در مجموع ۱۴۱ گروه موفق. RTL/LTR، light/dark، عرض 1280/390/320، نبود سرریز، drawer و Escape، خدمات و داده نقش‌ها، خانه خالی مدیریتی و نبود منوی دانشجو بررسی شدند. هر ترکیب نقش/زبان/تم یک مسیر سرویس را با ورود مستقیم و refresh بررسی می‌کند. تست‌های قبلی همه زیرمسیرهای مدیریتی، callback چهار نقش، PKCE، خروج، انقضا، storage event، پاک‌سازی cache، 401/403، خطای API و retry، null/empty، خدمات خاموش، redirect/embed و عدم افشای token را پوشش می‌دهند.

**حد بررسی:** تمام APIهای مرورگر intercept شده‌اند؛ بک‌اند زنده، Docker، Keycloak واقعی و SSO سرویس‌های تیم‌ها اجرا نشده‌اند. بررسی frontend جای smoke استقرار را نمی‌گیرد. داده fixture داخل محصول یا bundle تولیدی افزوده نشده است.

چهار فایل مرجع اصلی بازیابی و مشاهده شدند. تصویر طراحی در سمت چپ و نتیجه برنامه در سمت راست فایل‌های `*-comparison.png` است؛ دو سمت به عرض 1280 نرمال شده‌اند. نرمال‌سازی screenshot فیگما تقریبی است و سنجش پیکسلی محسوب نمی‌شود.

نام، شمارش، streak و تعداد پست‌های تصویر نتیجه از fixture قرارداد API می‌آیند؛ با مقادیر نمونه طرح برابر نیستند. آمار خدمات و درصد ۸۰٪ فاقد قرارداد به UI بازگردانده نشدند. منوی فعال تابع مسیر است؛ هایلایت مرجع به خانه تحمیل نشد. آیکن‌های SVG و فونت موجود دقیقاً asset اصلی فیگما نیستند؛ اختلاف ظریف شکل و وزن متن باقی است و تطابق پیکسلی ادعا نمی‌شود. تعداد کارت‌های feed از پاسخ می‌آید و برای شبیه‌سازی سه پست نمونه تولید نشده است.

۳۲ تصویر نتیجه (دسکتاپ و 390 برای ۱۶ ترکیب)، چهار مقایسه، چهار مرجع اصلی، `mobile-matrix.png` و `results.json` در `docs/t12-verification/` هستند. عرض 320 در JSON ثبت شده است. تصاویر فقط با نام و محتوای مصنوعی تست تولید شده‌اند. طرح مستقل برای dark/LTR/موبایل نداریم؛ بررسی آن‌ها عملکردی است.

## اجرای دوباره

از پوشه frontend، ابتدا `npm ci`؛ سپس `npm run build` و `npm run lint`.
Playwright و Chromium در محیط بررسی لازم‌اند و dependency محصول نیستند. برای T04 متغیر `T04_CHROMIUM_EXECUTABLE` و برای T05 تا T12 متغیر `T05_CHROMIUM_EXECUTABLE` مسیر Chromium را می‌گیرد؛ اگر Playwright بیرون پروژه نصب شده، `NODE_PATH` را تنظیم کنید. تست‌ها `node tests/t04-auth.cjs` تا فایل‌های متناظر T12 به‌صورت ترتیبی اجرا می‌شوند؛ تست‌های T05 تا T11 پورت 5197 مشترک دارند و نباید هم‌زمان اجرا شوند. T04 پورت 5198 و T12 پورت 5196 دارد. فرمان T12: `node tests/t12-final.cjs`.

## محدودیت و گام بعد

T06 و پذیرش بصری کامل T12 تا دریافت export کامل و بدون پوشیدگی دانشجو باز می‌مانند. درصد پروفایل همچنان BLOCKED_API است. شبکه اجتماعی بک‌اند demo است؛ لایک/ذخیره/ارسال پست، mark-as-read و SSO مستقل قرارداد تازه ندارند. refresh token flow پیاده نشده و محدودیت قبلی است.

گام بعد: مرجع کامل دانشجو برای نهایی‌سازی T06؛ سپس بستن پذیرش بصری T12. smoke روی استقرار واقعی با چهار حساب نقش و Keycloak واقعی نیز باید جداگانه انجام شود. هیچ endpoint، طرح پایین صفحه یا مقصد سرویس حدس زده نشد.

خروجی `Gradian-T12.zip` شامل کل کد ورودی، دو سند به‌روز، گزارش، تست‌ها و شواهد جاری است؛ node_modules، dist و cacheهای تولیدی داخل آن نیستند.
