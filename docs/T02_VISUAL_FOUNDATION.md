# T02 — پایه بصری پنل‌ها

تاریخ: 2026-10-19 | وضعیت: DONE | تسک بعد: T03 (شروع نشده)

## تغییرات

- قواعد پنل‌ها و responsive آن‌ها از globals.css به portals.css منتقل شدند؛ selector تکراری برای patch کردن ظاهر به انتهای globals افزوده نشد. فایل جدید در main.tsx پس از globals import می‌شود.
- رنگ، فونت، شعاع، gutter، عرض سایدبار و ارتفاع هدر در scope پوسته پنل‌ها توکن دارند؛ رنگ‌های عمومی Landing/Login تغییر نکردند.
- Vazirmatn متغیر با نام مجزای Gradian Portal به‌صورت محلی افزوده شد؛ وزن 100 تا 900 و سه subset عربی، لاتین و لاتین تکمیلی. منبع بسته @fontsource-variable/vazirmatn نسخه 5.3.0؛ مجوز OFL در src/assets/fonts/Vazirmatn-LICENSE.txt همراه فایل‌هاست. dependency یا lockfile پروژه تغییر نکرد.
- import قدیمی Google Fonts برای صفحات عمومی حفظ شده است؛ پنل‌ها از font-face محلی با نام جدا استفاده می‌کنند، بنابراین به موفقیت درخواست Google Fonts وابسته نیستند.
- رنگ‌های سطح و متن پنل‌ها برای dark به متغیرهای تم متصل شدند. direction از سند به ارث می‌رسد؛ سایدبار دسکتاپ و نمایش drawer موجود در LTR آینه می‌شود. رفتار auth، ناوبری و API دست‌کاری نشد.

## شواهد مرورگر

اجرا با Chromium در محیط بررسی، داده هویت آزمایشی در storage و بدون اتصال به بک‌اند واقعی انجام شد. مقدار آزمایشی نشست فقط در harness موقت بود و به محصول اضافه نشده است. درخواست‌های /api با پاسخ 503 و درخواست‌های Google Fonts با مسدودسازی کنترل شدند تا اختلاف تصویر وابسته به اینترنت نباشد.

- 14 حالت: چهار نقش فارسی روشن در عرض 1280؛ دانشجو و مشاور انگلیسی روشن؛ دانشجو و مشاور فارسی تیره؛ دانشجو و drawer مشاور فارسی روی 390؛ drawer مشاور انگلیسی روی 390؛ دانشجو انگلیسی روی 320؛ Landing و Login در 1280.
- در 12 حالت پنل، shell واقعاً موجود بود و دو subset محلی فونت (عربی و لاتین) در FontFaceSet وضعیت loaded داشتند. check وزن‌های 400، 500، 600، 700 و 800 موفق بود. subset لاتین تکمیلی فقط در صورت نیاز به کاراکترهای آن دانلود می‌شود.
- در تمام 14 حالت document.scrollWidth از viewport بیشتر نبود.
- در عرض 1280، سایدبار RTL در x=992 و LTR در x=0 با عرض 288 قرار گرفت. drawer باز در 390 فارسی x=102 و انگلیسی x=0 بود.
- ارتفاع نمای دانشجو 1978، استاد 927 و مشاور 800 در capture استفاده شد؛ min-height همچنان viewport است و ارتفاع محصول ثابت نشده است.
- تصاویر Landing و Login قبل و بعد بایت‌به‌بایت یکسان بودند. این مقایسه برای حالت فارسی روشن 1280 با شبکه کنترل‌شده است، نه ادعای بررسی همه حالات صفحات عمومی.
- screenshots و metrics در t02-visuals هستند؛ داده‌ها نمونه و غیرخصوصی‌اند. فریم مرجع، UI فیگما، مرورگر و ابزارها جزو محصول نیستند.

## بررسی کیفیت و مرز تحویل

- npm run build: موفق؛ 136 ماژول و سه فایل woff2 داخل dist.
- npm run lint: موفق، صفر error و همان سه warning react-refresh در AuthProvider / I18nProvider / ThemeProvider.
- build شامل tsc -b و بررسی واقعی TypeScript است؛ تست مجدد مستقل لازم نبود.
- تغییرات این مرحله در main.tsx فقط import CSS است؛ globals.css فقط قواعد پنل منتقل‌شده را از دست داده است. PortalLayout، router، auth، backend، ترجمه‌ها و API تغییر نکردند.
- ورود واقعی Keycloak، backend و عملکرد خدمات بررسی نشده‌اند. این مرحله تأیید پایه بصری است؛ T03، T06 و T12 هنوز باقی‌اند.
- بسته تحویل به‌صورت تجمعی T01+T02 روی Gradian(8) قابل اعمال است؛ فایل‌های مشابه جایگزین و پوشه‌ها ادغام شوند. پوشه پروژه حذف نشود. build، lint و typecheck برای بررسی محلی قابل اجرا هستند.
