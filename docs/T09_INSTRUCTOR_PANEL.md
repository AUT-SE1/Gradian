- navigation.config.ts: آیکن‌های اختصاصی استاد؛ ترتیب، عناوین و پنج مسیر موجود صحیح بودند و حفظ شدند.

- PortalLayout.tsx: نشان تأیید پروفایل و ساعت شمارش استاد؛ رفتار مشاور و ادمین حفظ شد.
- portals.css: اصلاح scoped فاصله گروه‌ها، دکمه پروفایل و کارت شمارش استاد، شامل LTR و رنگ‌های موجود dark.
- tests/t09-instructor.cjs: سناریوهای پذیرش با API کنترل‌شده.
- GRADIAN_SESSION_CONTEXT.md و GRADIAN_DASHBOARD_TASKS.md: نسخه 1.9 و وضعیت جاری T09.
