اصلاحات این سشن:

1. `frontend/eslint.config.js`: flat config با recommendedهای JS/TypeScript و Hooks، هشدار Fast Refresh، محیط browser و override محیط Node برای configها، ignore خروجی dist/node_modules. dependency جدید اضافه نشد و هیچ rule لازم برای پنهان‌کردن خطا خاموش نشد.
2. `frontend/package.json`: فقط script typecheck از `tsc --noEmit` به `tsc -b` تغییر کرد؛ lockfile ثابت ماند.
3. یادداشت وضعیت جاری در راهنمای قدیمی فرانت و دو سند اصلی به‌روز شدند.

سه هشدار lint در AuthProvider:47، I18nProvider:26 و ThemeProvider:23 به export hook و component در یک فایل مربوط‌اند. با فعال‌شدن lint آشکار شدند، کد این providerها تغییر نکرده است. این هشدارها مانع build نیستند؛ تفکیک فایل‌ها در این مرحله ضرورت ندارد.

هشدار npm درباره http-proxy مربوط به محیط بررسی است. نصب درباره deprecated بودن نسخه resolveشده ESLint هم هشدار داد؛ ارتقای وابستگی در T01 انجام نشد.
