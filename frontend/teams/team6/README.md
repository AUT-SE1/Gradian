# Team 6 frontend

This is the independent frontend application owned by team 6. The team may replace the starter with React, Angular, Vue, Svelte, or plain HTML/CSS/JavaScript.

## Local development

```bash
npm install
npm run dev
```

The default starter uses Vite only as a development server. It is not a requirement for the final implementation.

## Configuration

Copy `.env.example` to `.env` and set the team frontend URL, Core API URL and Keycloak issuer. Use Authorization Code + PKCE and keep access tokens out of URLs.

## Ownership

Backend owner group: `6`. The service keys and final routes belong in the Core Service registry and must remain stable once published.
